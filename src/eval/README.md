C++ accumulators fed by engine states and events. `summary` is the completed-trip diagnostic; `movement` is the M2.5 per-movement delay/travel-time and approach-queue report for one run (see `docs/reference/SIMULATION.md`); `lane_changes`, `segment_times`, `stop_lines`, `arrival_phases` and `dead_end_waits` are M3.2.8c diagnostics (CLI flags). HCM control delay, LOS letters, multi-seed aggregation and confidence intervals remain planned (M5).

`discharge` adds independent lane/cycle queue headways and startup estimates (M3.3.1a), with raw crossings and explicit unavailable reasons. See [contract](../../docs/reference/DISCHARGE.md); class filters and complete remap/source tracking remain pending.
