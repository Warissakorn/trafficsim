C++ accumulators fed by engine states and events. `summary` is the completed-trip diagnostic; `movement` is the M2.5 per-movement delay/travel-time and approach-queue report for one run (see `docs/reference/SIMULATION.md`); `lane_changes`, `segment_times`, `stop_lines`, `arrival_phases` and `dead_end_waits` are M3.2.8c diagnostics (CLI flags).
