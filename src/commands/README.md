Qt-free named document transactions and bounded snapshot Undo/Redo. History validates a candidate before publishing it; failed changes leave model/history/save state intact. Network operations support geometry, lane widths, reference-safe deletion, splitting, pockets and opposite carriageways. Connector operations provide creation, interior-point edits, retargeting, curve/straight reset and reference-safe deletion. Link/Lane changes share connector reanchoring; both deletion paths share route/input cleanup. History is in memory, not a persisted journal or plugin registry.
