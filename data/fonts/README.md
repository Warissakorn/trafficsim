Upstream Git blob: 34b48ab6f74867dbfce19410a2f452abef34e3ff
Local filename: NotoSansThai.ttf

The desktop loads this local file at startup so Thai text works offline even on systems
without a Thai font. This is data, not a runtime network dependency.
